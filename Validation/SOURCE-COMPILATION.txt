Native source provenance
========================
Windows workers compile Source/native directly.
Linux workers use the same sources after prepare_native.py gives each
profile-local include a unique guard. This avoids GCC/NVCC pragma-once
deduplication across isolated namespaces. Mathematical bodies are unchanged.
build.py performs this staging automatically and records the effective inputs.
