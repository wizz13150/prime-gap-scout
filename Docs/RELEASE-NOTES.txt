Prime Gap Scout 1.3.5
====================

Preserves the framed dashboard, its four metric cards, device/range frame,
Best and Recent tables, bottom cumulative counts and action bar. Adds a third
Statistics frame with two internal columns: cumulative gap sizes and disjoint
merit bands. Window fitting respects the monitor work area and selected rows.

Uses the Horizon icon and observes actual core/memory clocks. Start is directly
available on the Idle dashboard; STARTING appears during initialization.

Optimized cached dispatch covers the full 67–95-bit domain. Logical searches
continue across bit, high-word and pointwise retention-threshold boundaries,
without a general-engine fallback. Auto advances the cutoff in steps of two.

A resident native process retains its CUDA context and allocation between
physical pieces. Each piece keeps its own durable nonce, committed prefix and
completion receipt. Command reads and atomic receipt publication tolerate
transient Windows file-access conflicts; persistent failures stay explicit.
Pinned release artifacts avoid repeated executable/proof-library hashing;
mutable checkpoints always receive fresh integrity checks.

Active-work speed/averages exclude initialization and paused time. The existing
report, restart recovery, locked-export continuation and exact proof checks
remain supported. Public launchers contain neutral editable defaults.

See VALIDATION.md for actual tests and platform qualification limits. Historical
benchmark measurements are retained, not presented as new speed records.
Versions 1.3.3 and 1.3.4 remain withdrawn.

Live-menu progress follows the controlled session state, so an older saved
failure cannot replace Searching. Actual failure and paused states remain
visible; the correction is covered by production-renderer regressions.
