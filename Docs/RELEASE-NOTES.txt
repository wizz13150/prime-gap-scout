Prime Gap Scout 1.3.1 - operator-approved release

Fix a Windows owner-completion file sharing/access race that could end a valid
search with PermissionError while reading done.json. Completion polling now
allows a bounded transient I/O grace period and caches the accepted exact
receipt. Atomic receipt publication retries only the same fsynced bytes.
Persistent denial, missing evidence, wrong identity or corrupt metadata remains
an explicit failure and never becomes a successful completion.

Owner-wait failures are reported separately from timing failures. CUDA engines,
arithmetic, thresholds and checkpoint compatibility images are unchanged.
No automatic uploads or GPU setting changes. Operator validation completed before GitHub publication.
