Prime Gap Scout 1.3.3

Mining results
- Best, Recent and Statistics are displayed together for the same search range.
- Gap-size counts are cumulative; merit bands are disjoint. All merits at or
  above the target share one final row.
- Statistics use the complete committed range index, not just displayed results.
- Consecutive empty merit bands are combined on screen. Replay, rollback and
  reopening preserve the complete histogram.
- statistics.csv exports the range counts alongside the existing reports.
- Table spacing preserves exact lower-prime coordinates when the terminal fits.
  A small terminal requests more room rather than silently hiding result rows.

Windows process hosts
- Scout can start inside a Windows process host that prohibits Job breakaway.
  The enclosing host's limits remain in effect, and the suspended compute child
  must enter Scout's own kill-on-close nested Job before execution.
- Forced host termination closes the nested controller and child. A missing
  completion receipt is never converted into a successful completed search.

The CUDA engines, retained benchmark measurements and checkpoint compatibility
images are unchanged. Scout remains an independent offline search application.
