BUILD FROM SOURCE
=================
Tested toolchains: Python3.12, CUDA12.8, VS2022/MSVC14.36 on Windows;
Ubuntu24.04/GCC13 on Linux. Compilation does not require a GPU.

Install the build requirements in a local virtual environment:
  python -m pip install -r requirements-build.txt

EXACT PROOF RUNTIME
-------------------
The build bundles shared FLINT/GMP/MPFR libraries from a python-flint0.7.1
wheel. Its Python extension is not loaded; only the shared runtime and licenses
are included. Supply an explicit platform wheel, or retain the supplied matching
frontend/lib/proof directory and its fingerprinted manifest.

Windows wheel (use an x64 Native Tools Command Prompt):
  python -m pip download --only-binary=:all: --no-deps --platform win_amd64 --python-version 312 --implementation cp --abi cp312 --dest dependencies python-flint==0.7.1
  python build.py --proof-wheel dependencies/python_flint-0.7.1-cp312-cp312-win_amd64.whl --archs 86,120 --package

Ubuntu wheel (activate your Python virtual environment):
  python -m pip download --only-binary=:all: --no-deps --platform manylinux2014_x86_64 --python-version 312 --implementation cp --abi cp312 --dest dependencies python-flint==0.7.1
  CXX=g++-13 python build.py --proof-wheel dependencies/python_flint-0.7.1-cp312-cp312-manylinux_2_17_x86_64.manylinux2014_x86_64.whl --archs 86,120 --package

If the matching proof runtime is already bundled, omit --proof-wheel.
Use --archs86 or --archs120 to compile only one supported architecture.
Results: build/windows/pgn68/ or build/ubuntu/pgn68/. Copy the COMPLETE directory.
The native build uses one compiler thread and does not modify GPU settings.

SOURCE EXECUTION
----------------
After the native build:
  python frontend/pgn68.py --idle
Use --help for the complete public CLI. Results are local. Keep the workers,
metadata and runtime directories together. Preserve compatible historical worker
images when resuming a checkpoint pinned to their exact executable hash.

INDEPENDENT DIAGNOSTIC FIXTURES
-----------------------------
  python native/generate_diagnostic.py --check
This verifies274 fixed Euler/Jacobi cases using Python integer pow, without CUDA,
a compiler or a historical workspace archive. The optional write mode regenerates
the checked-in constants. Third-party reference acknowledgments remain intact.
