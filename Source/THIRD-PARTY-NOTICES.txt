Bundled software components
---------------------------
The application is frozen with Python and PyInstaller. Its Rich console uses
Rich and its included Python dependencies, including Markdown-it-py, mdurl
and Pygments. Package dist-info licence files are preserved in _internal where collected
by the freezer. No unused numerical Python dependency is required.

NVIDIA CUDA Runtime components are supplied for the corresponding workers.
They retain NVIDIA's own licence and redistribution terms. The optional Windows reference-comparison diagnostic uses the bundled
CUDA12.8 NVRTC and matching builtins pair when supplied by the build Toolkit;
it reports unavailability when that optional pair is absent. No NVIDIA driver is included; the compatible
installed driver is used.

The Ubuntu package also bundles libstdc++.so.6 and libgcc_s.so.1. The exact
Ubuntu gcc-13-base copyright text, including the GCC Runtime Library Exception,
is included as THIRD-PARTY-LICENSES/Ubuntu-gcc-13-base-copyright.txt.

Exact installed licence/copyright texts copied for this release are under:
  THIRD-PARTY-LICENSES/
Their file names, byte lengths and SHA-256 hashes are recorded in:
  THIRD-PARTY-LICENSES/MANIFEST.json

These include Python's installed licence, PyInstaller's complete COPYING
(including its application/bootloader exception), Rich, Markdown-it-py,
mdurl, Pygments, NVIDIA CUDA Runtime and NVRTC licence texts, and collected
licences from actual frozen package metadata. Ubuntu library copyright
files are included for the available Python/OpenSSL/libffi/Expat/XZ/bzip2/
readline/SQLite/ncurses/zlib/libyaml dependencies.

Windows system/Visual C++ runtime files and Ubuntu system libraries remain
subject to their own suppliers' terms. This notice does not replace those
terms or relicense any third-party component. Components provided solely
by the operating system or installed driver are not represented as PGN code.

No diagnostic or report is automatically uploaded by this application.

Exact endpoint proof runtime
---------------------------
Shared FLINT, GMP and MPFR libraries are supplied from the explicitly selected
python-flint0.7.1 wheels. The Python extension itself is not required by the
application. FLINT uses LGPL terms; preserve the exact accompanying wheel license
texts under THIRD-PARTY-LICENSES/proof-runtime and the runtime manifest fingerprints.
Sources and upstream licensing information:
  https://github.com/flintlib/flint
  https://github.com/flintlib/python-flint
  https://gmplib.org/
  https://www.mpfr.org/
Library and wheel SHA-256 values are recorded in frontend/lib/proof/<platform>/manifest.json.
The application calls the proved fmpz_is_prime predicate, not probable-prime acceptance.
